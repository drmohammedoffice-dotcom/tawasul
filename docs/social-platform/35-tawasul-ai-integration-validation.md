تاريخ التنفيذ: 4 نوفمبر 2026.  
المرجع السابق: `34-tawasul-ai-models-activation-report.md`.  
الأدلة القابلة لإعادة التشغيل: `ai-service/validation-results/latest.json` + الأوامر أدناه.  
لم يُمسّ `baseline-1.0.0`. لم يُنزَّل Qwen3-VL. لا ادعاء سعة 100 ألف مستخدم.

npm run fixtures:validation

# أو: node --env-file=.env scripts/run-integration-validation.mjs

مدة الجولة المسجّلة هنا ≈ **258 ثانية** على لابتوب التطوير (RTX 4060 Laptop 8GB، RAM ~16GB، نماذج نصّية على CPU `LLAMA_NGL=0`).

## 1. تدقيق الحالة الحالية (تنفيذ فعلي)

| المكوّن | الحالة الفعلية | ملاحظة |
| --- | --- | --- |
| Qwen3-4B + llama-server | جاهز | `127.0.0.1:8081` health=200؛ GGUF على قرص ~2.33GB |
| EasyOCR ar+en | جاهز | بديل PaddleOCR على Windows |
| faster-whisper-small | جاهز | مع `av==12.3.0` |
| BGE-M3 | جاهز | dim=1024 محلياً |
| Nest `AI_SERVICE_URL` | مربوط | `OFFLINE_AI_MODE=true`؛ الرمز يطابق `AI_INTERNAL_TOKEN` |
| خدمة `:3100` | تعمل | uptime طويل أثناء الاختبار |
| تشغيل/إيقاف | جزئي | `npm run dev` / SIGINT يوقف الطابور وllama؛ لا سكربت start/stop مستقل؛ `dist/` غير مبني لـ `npm start` |
| Model Registry | حقيقي | `manifests/models.registry.json` + علامات `.installed` |
| Task Queue | حقيقي داخل العملية | `Map` + استطلاع؛ BullMQ/Redis **غير مستخدمين** رغم وجود التبعية |
| Cache | حقيقي بالذاكرة | TTL؛ يضيع عند إعادة التشغيل |
| اتصال AI↔Postgres | لا | Nest يملك `ContentAnalysisJob` / `ContentUnderstanding` |
| مسار Nest للنماذج الثقيلة | **غير موصول** | Nest يستدعي فقط `POST /v1/text/analyze` (قاموس متزامن). لا يرسل OCR/Whisper/Embed/GGUF عبر `/v1/jobs` عند النشر |

خريطة التشغيل الحقيقية:

```
نشر post/reel → رجوع فوري
  → ContentAnalysisJob (Postgres)
  → TawasulAiClient.analyzeText → /v1/text/analyze (lexicon فقط)
  → ContentUnderstanding
  → الترتيب يستخدم المواضيع فقط إذا hybridRanking=ON (حالياً OFF)
```

النماذج الثقيلة قدرة على الخدمة الجانبية ومُثبتة باختبارات HTTP/طابور، **وليست** على المسار الساخن لنشر Nest اليوم.

## 2. نتائج Qwen3-4B / القاموس

مصدر: `validation-results/latest.json` → `qwen`.

| المقياس | القيمة |
| --- | --- |
| الحالات | 11/11 نجاح مسار القاموس + وظيفة `text.analyze` |
| زمن القاموس | ~2–24 ms |
| زمن الوظيفة (مع إثراء GGUF) | ~1.5–6.1 s لكل نص (CPU) |
| VRAM أثناء الاختبار | ~1047→1048 MiB (لا تحميل GPU للنص؛ `LLAMA_NGL=0`) |
| JSON من GGUF | قابل للتحليل في كل الحالات المختبرة |

ملاحظات جودة مهمة (ليست نجاحاً شكلياً):

1. **القاموس أفضل من GGUF لتصنيف العربية العراقية/الفصحى في هذه الجولة** (مواضيع مستقرة مثل `electric_cars` / `iraq_local`).
2. GGUF أحياناً يُرجع موضوعات بالصينية لنص عربي فصيح (حالة `msa`) — غير مقبول كعقد تقديم عربي دون ضبط لغة الخرج.
3. حالة `no_invent`: GGUF التزم بالطبخ/الكباب ولم يخترع سيارات؛ **القاموس** وسم خطأً `cars` و`medicine` بسبب تطابقات سطحية — مشكلة taxonomy معروفة.
4. لا يوجد في عقد GGUF الحالي مفاتيح إلزامية لـ hashtags/summary منفصلة؛ الخرج الفعلي `topics` + `keywords` فقط.
5. Nest **لا يستهلك** حقل `enrichment` من مسار الوظيفة؛ يعتمد شكل القاموس فقط.

PaddleOCR ما زال غير جاهز على هذا البناء Windows (oneDNN).

## 5. نتائج BGE-M3 / الدلالة

| المقياس | القيمة |
| --- | --- |
| dim | **1024** |
| تحميل محلي | نعم |
| cosine(عربية↔إنجليزية متقاربة المعنى) سيارة/بغداد | **0.8217** |
| cosine طبخ/كباب | **0.7545** |
| cosine غير متقارب (رياضيات↔مباراة) | **0.5309** |
| أول batch (6 نصوص) | ~47 s (تحميل بارد) |
| دفعة لاحقة أصغر | ~17 s |

**التكامل داخل التطبيق:** لا pgvector ولا مسار بحث دلالي في Nest/search حالياً.

### خطة تكامل Semantic Search (دون كسر البحث الحالي)

1. الإبقاء على البحث المعجمي الحالي كمسار افتراضي.
2. إضافة جدول/مخزن جانبي اختياري لـ embeddings العامة فقط (منشورات/ريلز) خلف علم ميزة `semanticSearch=false` افتراضياً.
3. عند التفعيل: استعلام HNSW/pgvector أو فهرس قرصي محلي للمرشحين، ثم دمج نتائج كـ *إعادة ترتيب ثانوي* للمرشحين المعجميين فقط (shadow أولاً).
4. عدم فهرسة الرسائل الخاصة أو محتوى المحادثات.
5. قياس Precision/NDCG مقابل البحث الحالي قبل أي تفعيل للمستخدمين.

## 6. اختبار التكامل الموحّد (نص + صورة + صوت)

سيناريو متوازٍ عبر الطابور:

| الفرع | النتيجة |
| --- | --- |
| نص عراقي + هاشتاغات | مواضيع `electric_cars` / `iraq_local` / … + `enrichmentOk=true` |
| صورة | OCR `BAGHDAD ELECTRIC CAR` + caption |
| صوت إنجليزي | تفريغ مطابق |
| Cache القاموس | الطلب الثاني `cached=true` ونفس `hash` خلال ~16 ms |
| الزمن الكلي للسيناريو | ~18.3 s |

النشر في Nest يبقى غير متزامن (fire-and-forget). لم يُثبت في هذه الجولة مسار Nest→`/v1/jobs` متعدد الوسائط — الفجوة موثّقة أعلاه.

منع التكرار: طبقة Nest تتخطى عند نفس `contentHash` + `lexicon-1.0.0` ready؛ طبقة AI cache بالتجزئة للقاموس؛ طابور AI يزيل التكرار بـ idempotencyKey/hash.

## 11. ما اجتاز / ما لم يجتز

### اجتاز
- تشغيل الخدمة `:3100` ووضع offline.
- قاموس عربي/عراقي/إنجليزي سريع.
- إثراء GGUF JSON على مسار الوظائف.
- EasyOCR للإنجليزية والخلط والإعلانات المائلة (إنجليزي).
- Whisper للإنجليزية الواضحة.
- BGE-M3 dim=1024 وفصل تشابه متقارب/متباعد.
- تكامل طابور نص+صورة+صوت مع cache قاموس.
- رفض الحقول الخاصة و401 بدون رمز.
- بقاء baseline وعدم كسر النشر عند وجود AI.

### لم يجتز / ناقص
- ربط Nest بالنماذج الثقيلة (`/v1/jobs`) عند التحليل.
- استهلاك Nest لـ GGUF enrichment.
- OCR عربي دقيق (انعكاس RTL).
- تفريغ لهجة عراقية حقيقية (لا عيّنة صوتية أصلية في البيئة).
- Semantic Search داخل التطبيق.
- متانة الطابور/Cache عبر Redis/BullMQ.
- `npm start` دون `build` (`dist/` غائب).
- Qwen3-VL غير منزّل (مقصود).
- ضبط لغة خرج GGUF للعربية (ظهر صيني في حالة).

## 12. المشكلات المتبقية (مرتبة)

1. فجوة العقد Nest↔AI (قاموس فقط على المسار الساخن).
2. جودة OCR العربي (bidi/reshaper) قبل أي ادعاء إنتاج.
3. عيّنات صوت عراقية حقيقية + قياس WER.
4. منع وسم القاموس الكاذب عند النفي («دون ذكر سيارات»).
5. إجبار لغة JSON في قالب Qwen3 للنصوص العربية.
6. ترحيل الطابور إلى Redis/BullMQ عند الحاجة للثبات.
7. بناء `dist` وسكربت تشغيل/إيقاف واضح للخدمة.
8. قرار VL-2B بعد الموافقة والترخيص.

## 13. توصيات المرحلة التالية

1. **Shadow-only:** وصل اختياري لنتائج OCR/Embed كحقول فهم إضافية دون لمس ranking.
2. إصلاح RTL لـ EasyOCR وقياس دقة عربية بمجموعة ذهبية صغيرة.
3. ضبط قالب GGUF (`language=ar` / تعليمات صارمة) وإسقاط enrichment غير العربي.
4. جمع 10–20 مقطعاً صوتياً عاماً (غير خاص) بلهجة عراقية لقياس Whisper.
5. تصميم جدول embeddings اختياري + علم ميزة مغلق.
6. بعد موافقة المالك فقط: تنزيل Qwen3-VL-2B Q4 + mmproj واختباره منفصلاً عن حمل النص.

## 14. خلاصة القرار

التكامل **جزئي وصادق**: النماذج المحلية تعمل ومُقاسة، والحماية offline موجودة، وbaseline محفوظ.  
لكن **محرك Tawasul AI لم يكتمل كمسار تحليل متعدد الوسائط داخل Nest**؛ المسار الإنتاجي الحالي للفهم عند النشر هو القاموس غير المتزامن فقط.  
الجولة التالية يجب أن تُغلق فجوة العقد وتصلح جودة العربية (OCR/الخرج) قبل أي تفعيل ranking يعتمد على AI.
